## Agent Workflow

- Use the `agent-workflow` skill to size, implement, and verify software work. Follow applicable instructions in the directories you touch.
- Start with `docs/agent-workflow/context-index.md` when present. Read the linked topics relevant to the task and the active change record when resuming work.
- Use `agent-workflow-onboarding` when the user requests onboarding or missing project knowledge materially affects nontrivial work. Keep quick tasks focused.
- Carry authorized work through validation. Continue through routine checkpoints and recoverable failures. Ask for input only when a business decision, blocker, scope change, or authorization requires the user.
- Honor the host's permissions and project trust settings. Keep hooks opt-in and leave user settings and existing hooks alone.
