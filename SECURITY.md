# Security policy

Report suspected vulnerabilities privately. On the GitHub repository, open **Security and quality** and select **Report a vulnerability**. If private reporting is unavailable, contact a repository maintainer through a private method listed on their GitHub profile. If you need to request a private channel, keep the request free of vulnerability details. [GitHub private reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected version or commit, operating system, expected and observed behavior, and enough context to assess the impact. Remove credentials and private project data before sharing any material. Keep vulnerability details out of public issues, pull requests, and discussions while maintainers assess the report.
